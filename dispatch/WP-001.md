## Goal
Produce an independently verified reconciliation of the NHRF forest recommendation research: reproduced counts, validated statement records, implementation status for each of the 19 recommendation groups, a correction ledger, and proposed publication claims, using the frozen research snapshot already in this repo.

## Scope
`reviews/NHRF-VERIFY-002/`

## Rules
No em dashes. Use the frozen research snapshot already in the repo; do not alter the published research itself, that step waits for separate adjudication approval. Keep the numerical reconciliation table separate from the narrative findings. State explicitly, for every unresolved item, what evidence would resolve it; do not describe partial verification as complete agreement. Distinguish arithmetic reproduction from source document verification. Cite primary sources for every implementation status claim.

## Expected payload (done criteria)
`reviews/NHRF-VERIFY-002/reconciliation.md` contains a table with columns Metric, Published, Sol, Fable, Adjudicated, Evidence, Status covering the source document counts, the 340 forest recommendation records, the 216 statements, the 19 groups, and each group's frequency.
`reviews/NHRF-VERIFY-002/statement-validation.md` records, for each of the 216 statements, whether it survives verification, needs correction, or is unverifiable, with the source passage cited.
`reviews/NHRF-VERIFY-002/implementation-status.md` contains a table with columns ID, Published count, Verified count, Original status, Adjudicated status, Evidence, Remaining issue for each of P01 through P19.
`reviews/NHRF-VERIFY-002/correction-ledger.md` lists every correction made to a published figure or status, with the reason.
`reviews/NHRF-VERIFY-002/proposed-claims.md` lists the publication claims the adjudicated evidence supports, and separately, every item that remains unresolved and the exact evidence needed to resolve it.
